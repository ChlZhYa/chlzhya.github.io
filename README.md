# Flow 浮流

一个本地优先的个人记录站点。学习流水按日期呈现短记录，感悟文章留给较长的思考。仓库中的五篇文章是可阅读的示例，不会被当作使用者自己的记录。

## 本地运行

需要 Node.js 18 或更新版本。无需安装依赖或构建。

```sh
npm start
```

打开 <http://127.0.0.1:4173>。运行 `npm run check` 可检查 JavaScript 语法。服务器只绑定本机地址，静态资源来自 `dist/`。

## 记录与备份

点击“写一条”可选择学习流水或感悟文章，填写日期、分类、标签和正文。保存成功后记录进入当前浏览器的 `localStorage`，并打开阅读页。搜索、分类和日历会读取这些记录。正文是纯文本，段落换行会保留。

页脚和“关于”页提供 JSON 导出。文件使用 `{ "version": 1, "entries": [...] }` 结构，只包含使用者自己写的记录，不包含示例。当前版本不支持导入、删除、账户、同步或公开发布。清除站点数据、使用无痕窗口或更换设备都可能造成记录丢失；请定期导出文件另存。若读取到损坏的本地数据，页面会提示并停止写入，避免覆盖原数据。若写入失败，表单内容会保留并显示错误。

## 文件

- `dist/index.html` 是页面结构与原生搜索、写作对话框。
- `dist/styles.css` 是响应式排版与动效。
- `dist/app.js` 负责路由、渲染、检索和本地保存。
- `dist/data.js` 保存五篇只读示例。
- `dist/assets/flow-ribbon.png` 是首页的透明主视觉。
- `server.mjs` 是本地静态服务器。

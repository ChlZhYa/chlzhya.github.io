# Flow 浮流

一个保存在浏览器里的个人念头空间。Flow 收下观察、小想法和突然想通的瞬间；文章留给较长的思考。仓库内有六条 Flow 和两篇文章示例，均明确标为“示例”。

## 本地运行

需要 Node.js 18 或更新版本，无需安装依赖或构建。

```sh
npm start
```

打开 <http://127.0.0.1:4173>。运行 `npm run check` 检查语法，`npm test` 验证日期、筛选与记录合并规则。服务器运行时，`npm run smoke` 检查静态资源、文件类型和只读边界。

`npm run test:writer` 在受控的浏览器 API 替身中执行实际写作处理函数，复验等待写锁、存储配额错误和舍弃失败时的输入保留。它补充浏览器交互验证，不替代真实页面测试。`node scripts/writer-repro.mjs 9cf224b` 可对照修复前的两个故障输出。

## 浏览与记录

首页默认显示本月 Flow。环形日历按真实记录数标出活跃日期；点击日期筛选，再点一次恢复整月。月份箭头切换月份，分类可与日期一起筛选。“全部日期”跨月份浏览，“回到本月”恢复默认范围。画布呈现前五条匹配记录，其余记录在下方继续展示，每条只出现一次。

卡片直接显示至多三行正文摘要，点击卡片任意位置可打开阅读页。自动标题与正文首行完全相同时只展示一次，完整内容仍按原文保存。

点击“记一笔”可写 Flow 或文章。Flow 从正文开始，标题可以留空，保存时取正文第一条非空行作为标题，最多 48 个字符；文章需要标题。日期、分类和标签可补充填写。正文按纯文本保存，搜索涵盖两种记录。

写作窗口的“稍后继续”、关闭按钮和 Esc 会保留当前标签页的草稿，刷新同一标签页后自动恢复。草稿可包含尚未填完的字段。关闭标签页、清除站点数据或浏览器拒绝会话存储时，草稿可能丢失；页面会提示无法在刷新后恢复的情况。每个标签页只保留一份草稿，可明确舍弃后开始另一条。

打开自己保存的记录可以修改，示例内容只读。若修改期间别处改变或移除了同一记录，保存会拒绝覆盖并保留输入，可明确选择“另存为新记录”。其他记录的更新会并入最新快照。安全写入依赖浏览器 Web Locks；不支持时页面会保留表单并提示复制内容。

记录使用浏览器的 `localStorage`，键为 `flow-journal-v1`，快照结构为 `{ "version": 1, "entries": [...] }`。旧分类“AI / Agent”“开发”“阅读”仍可读取，并归入“学习”筛选。旧的 `#/journal` 链接仍可访问 Flow，新的首页地址是 `#/flow`。

页脚和“关于”页可导出 JSON 备份，导出时重新读取最新记录，只包含用户自己的内容，不包含示例。当前版本没有导入、删除、账户、同步或公开发布。清除站点数据、使用无痕窗口或更换设备都可能造成记录丢失。若本地数据无法读取，页面会提示并暂停保存，以免覆盖原数据；写入失败时表单内容会保留。

## 文件

- `dist/index.html` 提供页面外壳与原生对话框。
- `dist/styles.css` 实现响应式画布、日历和动效。
- `dist/app.js` 负责路由、渲染、检索和本地保存。
- `dist/flow-model.js` 负责纯日期、分类和筛选逻辑。
- `dist/entry-model.js` 负责快照校验、新建、修改和冲突判定。
- `dist/data.js` 保存只读示例。
- `server.mjs` 提供本机静态服务器。

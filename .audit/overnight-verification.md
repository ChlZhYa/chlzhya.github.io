## 布局

1435px 桌面和 390px 手机的最终截图分别为 `design/v2/overnight-desktop.png`、`design/v2/overnight-mobile.png`。肉眼检查保留了选定稿的错落关系、冷白蓝紫和圆环日历，五张卡片都有正文，文章仍在独立区域。

实际窗口宽 320 / 390 / 768 / 1100 / 1435px，页面宽分别为 305 / 375 / 753 / 1085 / 1420px（滚动条占用 15px）。卡片之间、介绍与日历之间没有相交。圆形日期直径为约 24 / 24 / 28 / 28 / 28px；相邻圆形目标最近边缘仍有约 0.31 / 4.49 / 0.49 / 0.49 / 0.49px 空隙。数据见 `overnight-geometry.json`。

最初用轴向包围盒判断圆形日期，误报了对角方向的矩形交叠。随后改用真实圆心距离减去半径之和，并检查 CSS 的 50% 圆角。这里记录的是修正后的圆形几何结果，没有把第一次误报算作缺陷修复。

## 独立评审发现与修复

gpt-6-astra 对 `9cf224b` 复现两个 P2。等待写锁时舍弃并换草稿，会保存未提交的新版；草稿 setItem 配额失败后，舍弃跳过 removeItem，导致旧草稿刷新后回来。两者均接受。`ee7fc09` 在提交时捕获输入并冻结写作控件，同时阻止等待期间舍弃和 Esc；舍弃总是尝试移除持久草稿，仅在成功后宣布完成。

同一份 `scripts/writer-repro.mjs` 运行旧提交，输出误保存 B、舍弃后恢复 A。运行当前版，输出只保存提交的 A、舍弃后无草稿。另验证了移除被拒绝时保留原文且不宣布成功、草稿写入失败后内存仍保留新内容、不支持锁和正式写入失败时均保留输入。

gpt-6-astra 对最终代码 `ee7fc0951333d46bfbfae83ce3e4d7b6576f234f` 独立复核通过，没有剩余已证实的实质缺陷。复核者再次运行语法、10 个行为测试、受控复验、HTTP smoke 和 diff 空白检查；浏览器结果仍明确归属于 root 的实际操作。

# 夜间自主优化复盘

2026-10-23。此文件记录可审阅的选择、依据和验证，不是逐字推理过程。

## 这一轮为什么这样改

你选的是第二张设计稿。冷白蓝紫、散落的念头卡片、环形日历和 Flow / 文章分区已经是明确方向，因此这轮围绕“记录、回看、继续写”打磨，没有再次替你换一种视觉风格。

基线页面的卡片只露标题，正文必须点开。写作窗口关闭后还能继续，但刷新会丢掉未提交输入。真实记录只有新建入口，写错后无法修改。代码检查还发现容量上限前后不一致，以及导出可能读取旧缓存。

## 设计取舍

| 选择 | 原因 | 边界 |
| --- | --- | --- |
| 卡片显示几行正文，自动标题重复的首行只展示一次 | 在画布上就能读到念头本身 | 长内容仍有阅读页 |
| 同标签页临时草稿 | 解决关闭窗口和刷新时丢输入 | 关闭标签页或清除站点数据后不保证恢复 |
| 允许修改自己的记录 | 保留原链接和记录身份，能补充或纠错 | 示例只读 |
| 比较修改基线，串行提交 | 其他标签页的新内容不能被旧表单静默覆盖 | 需要浏览器支持 Web Locks；不支持时保留输入并说明 |
| 保留 version1 存储格式 | 原有内容、分类、链接继续读取 | 不做账户、云同步、公开部署或数据库迁移 |

这是 Experience First 的实际取舍，把“能安心记下并继续写”放在新功能数量前面。Model the Domain 让新建、修改、修改基线和临时草稿各有明确含义。Prove It Works 要求在真实页面复现和复验，语法检查单独列出。
